# MQTT Trust Gateway 1.4.2

## Device connection health

- The 30-day Uptime bars now describe the final reliable status observed for each UTC day: green when the day ended online without an observed outage, yellow when it recovered after an outage, red when it ended offline, and gray when no reliable online/offline status was observed.
- A bar color does not claim complete coverage. Its tooltip continues to show the observed online, offline, and unknown durations.

## Compatibility

- This release changes no SQLite schema, CA material, device private keys, MQTT credentials, or existing Rules.
