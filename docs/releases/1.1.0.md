# MQTT Trust Gateway 1.1.0

## Features

- Signed Stable/Beta release discovery and update notifications.
- Settings → System Updates with release review, fresh authentication, progress,
  operation details, version history and guarded manual rollback.
- Independent rootless systemd updater; no Podman socket inside Admin.
- Consistent verified recovery snapshots preserving SQLite, CA, certificates,
  CRLs, configuration, Quadlets, retained messages and persistent MQTT sessions.
- Isolated versioned migrations, functional mTLS/WSS/MQTT/ACL health checks,
  automatic pre-commit rollback and recovery after controller interruption.
- Configurable checks, notifications and snapshot retention; optional host GPG
  encrypted snapshot export.
- Contextual certificate and update Help with interactive themed Mermaid guides.

## Upgrade and security

Existing installations require a one-time source upgrade containing the host
updater and broker maintenance gate. Preserve your existing environment and
runtime. Configure the independently verified release public key, then run
`./gateway updater-enable` as the rootless Gateway owner.

The updater never regenerates the CA. MQTT clients disconnect during installation
and must reconnect. Rollback is refused if newer persistent changes would be
lost. Local recovery snapshots contain private keys and remain unencrypted;
protect the host storage and use encrypted offline exports where required.

Automatic installation, offline release import and host operating-system/
Podman/systemd/updater-source replacement are outside this release's scope.
See the [operations guide](https://github.com/MarcioBulla/MQTT-Trust-Gateway/blob/main/docs/system-updates-operations.md)
and [release trust policy](https://github.com/MarcioBulla/MQTT-Trust-Gateway/blob/main/docs/release-publishing.md).
