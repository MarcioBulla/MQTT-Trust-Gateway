# MQTT Trust Gateway 1.4.3

## Device connection health

- A Health Check owner can now explicitly allow selected active, enabled, trusted identities to read its status topic.
- A permitted reader must use custom Rules with a matching Subscribe Rule and no matching Publish Rule. This keeps status publication exclusive to the owning device, while allowing an authorized observer to subscribe.
- Uptime tooltips now present the UTC date, final observed status, and Online, Offline, and Unknown durations in `HH:MM`.

## Compatibility

- This release changes no SQLite schema, CA material, device private keys, MQTT credentials, or existing Rules. Save the Health Check and apply pending broker changes to activate reader access.
