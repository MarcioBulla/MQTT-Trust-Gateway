# MQTT Trust Gateway 1.4.1

## Device connection health

- The Trusted Devices uptime column now presents only its 30 daily bars. Each bar retains its accessible tooltip with date, observed uptime, online/offline/unknown durations, and coverage.
- Configure each monitored device with a distinct Health Topic, Online Payload, and Offline Payload / LWT. Payloads are exact, distinct UTF-8 values from 1 to 128 bytes; existing configurations retain `online` and `offline` defaults.
- The monitor maps configured values to online/offline state while preserving its QoS 1, retained-message, LWT, grace-period, and replay safety checks.
- The Device Health Help includes an AutoBoot example: use `AutoBoot/availability` with `online` and `offline`. `AutoBoot/state` remains an ON/OFF application-state topic.

## Compatibility

- This release changes no SQLite schema, CA material, device private keys, MQTT credentials, or existing Rules. Apply pending broker changes after editing a device Health Check configuration.
