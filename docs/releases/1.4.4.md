# MQTT Trust Gateway 1.4.4

## Device and table improvements

- Added a **Features** column to Trusted devices. It distinguishes restricted topic Rules from planned certificate renewal capabilities.
- Restricted Rules now recognizes prefix-scoped filters such as `devices/#` as limited access. The tag is gold when custom Rules contain no `#`, teal when `#` is scoped beneath a prefix, and absent when the unrestricted `#` filter is present.
- Table column visibility is saved per authenticated user. The column chooser keeps its standard order and visibility controls.
- Centered device and certificate status values and improved authorization switch alignment.

## Renewal planning

- Expanded the WIP Renew tab with separate device-license and Gateway CA renewal planning sections.
- Added disabled placeholders for automatic-renewal thresholds and CA renewal announcement topic and message template. These controls do not schedule renewal, issue certificates, rotate the CA, or publish MQTT messages.

## Gateway schema

- Added additive schema migration 4 to initialize per-device renewal planning flags while preserving existing devices and certificates.

## Compatibility

- Existing CA material, certificates, device credentials, broker Rules, and persisted table preferences remain intact.
- Renewal configuration is still unavailable; its fields are visual WIP placeholders.
