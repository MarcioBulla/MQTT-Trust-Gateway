# MQTT Trust Gateway 1.1.1

- Fix host release discovery: request GitHub JSON for release metadata and binary
  content for signed assets. This prevents HTTP 415 before installation.
- Add transport regression coverage and live public discovery validation to the
  release pipeline.
- Include all System Updates, recovery and contextual Help features introduced
  in [1.1.0](https://github.com/MarcioBulla/MQTT-Trust-Gateway/blob/main/docs/releases/1.1.0.md).

The initial 1.1.0 release was withdrawn during final live verification. Its tag
and image digests are preserved. Use **1.1.1** for installation and the one-time
source bootstrap. The release trust key, device CA and persisted data format are
unchanged. See the [operations guide](https://github.com/MarcioBulla/MQTT-Trust-Gateway/blob/main/docs/system-updates-operations.md).
