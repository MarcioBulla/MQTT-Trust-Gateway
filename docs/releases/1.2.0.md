## Update

Install through **Settings → System Updates** on a Gateway with the signed
rootless updater enabled. Review the release and complete the confirmation and
fresh authentication. The coordinated update snapshots persistent state and
verifies functional health before committing.

Existing installations without the host updater require the one-time source
bootstrap described in the [operations guide](https://github.com/MarcioBulla/MQTT-Trust-Gateway/blob/main/docs/system-updates-operations.md).
The release trust key is unchanged. Reload an already-open browser tab after
updating to load the new interface.
