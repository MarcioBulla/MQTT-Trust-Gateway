# MQTT Trust Gateway 1.2.1

## TLS compatibility checks

- Keep TLS 1.2 as the minimum for native MQTT/TLS and MQTT over WebSockets.
- Verify exact TLS 1.2 and TLS 1.3 handshakes on both listeners during the
  updater's functional health check, including an authorized QoS 1 publish and
  subscribe round trip.
- Reject an update before commit if either listener cannot complete the TLS
  compatibility checks.

Mosquitto 2.x interprets `tls_version tlsv1.2` as a minimum, so TLS 1.2 and TLS
1.3 are allowed. Older TLS versions remain disabled. The existing CA, mTLS
authentication and device certificates are unchanged.

## Update

Install through **Settings → System Updates** on a Gateway with the signed
rootless updater enabled. Review the release and complete the confirmation and
fresh authentication. The coordinated update snapshots persistent state and
verifies functional health before committing.
