# MQTT Trust Gateway 1.5.0-dev.3

Beta-channel development prerelease.

- Accept the device's signed CSR in the `csr` JSON field on the PKI CSR topic. Existing devices using `pem` are still supported.
- Certificate installation continues to use `pem`. The Gateway still verifies the CSR signature and requires the exact registered Device ID as the subject CN.

Gateway CA migration remains under development.
