# MQTT Trust Gateway 1.4.5

## License summary consistency

- Gateway Overview and Device Licenses use the same effective certificate status, including trust and expiration date.
- **Active licenses** includes certificates that remain valid, including those in the 30-day **Expiring soon** window. **Expiring soon** is a subset of Active licenses, so those totals intentionally overlap.
- **Expired or revoked** includes expired, revoked, and blocked certificates. Both views exclude archived and deleted licenses.
- The shared status function keeps Dashboard API totals and Device Licenses cards aligned.
- Gateway Service Health Help describes these categories and exclusions.

## Compatibility

- No database migration is required.
- Certificate, CA, broker, and device state are unchanged.
