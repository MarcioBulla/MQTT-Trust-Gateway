# MQTT Trust Gateway 1.5.0-dev.1

Development prerelease for testing on the Beta channel.

- Start a device certificate renewal with a device-generated CSR from **Devices & certificates → Edit → Renew**. Select an active certificate issued by the local CA, review the five editable PKI topics, and select **Request CSR**. Use **Refresh status** to follow the operation.
- The device must be authorized and use compatible custom publish and subscribe Rules. The Gateway reserves the configured PKI topics and keeps the current certificate valid during the operation.
- **Copy certificate** in the device's Licenses actions opens the public PEM for copying after authorization.

Automatic renewal scheduling and Gateway CA rotation remain in development. The AutoBoot ESP flow has not yet been verified end to end.
