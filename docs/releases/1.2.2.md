# MQTT Trust Gateway 1.2.2

## Sensitive information visibility

- Allow any non-negative whole-number reveal timeout in **Settings → Account security**.
- Set the timeout to `0` to disable automatic timeout. Reveals still end on manual hide, page blur or visibility loss, logout, or session expiry.
- Keep server-side reveal grants bound to the current administrator session.
- Add contextual Help for the visibility policy and document its security boundaries.

## MQTT Manager

- Avoid adding narrower MQTT subscriptions already covered by the default `#` subscription, preventing duplicate observations of matching publications.

## Update

Install through **Settings → System Updates** on a Gateway with the signed rootless updater enabled. Review the release and complete the confirmation and fresh authentication. The coordinated update snapshots persistent state and verifies functional health before committing.
