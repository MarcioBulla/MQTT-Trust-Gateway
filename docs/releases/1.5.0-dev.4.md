# MQTT Trust Gateway 1.5.0-dev.4

Beta-channel development prerelease.

- In Edit Device → Renew, approve each verified CSR manually or configure a case-sensitive CN to accept automatically. The choice is saved when starting a renewal request.
- Request CSR automatically uses the most recent eligible local certificate for authorization and history.
- Issued certificates still use the registered Device ID for MQTT authentication and ACLs.

Gateway CA migration remains under development.
