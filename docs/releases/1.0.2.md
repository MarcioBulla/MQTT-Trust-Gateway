# MQTT Trust Gateway 1.0.2

Patch release for protected certificate downloads and device certificate renewal.

## Changes

- Protected issuer-chain downloads now open the existing step-up authentication
  dialog and retry after verification.
- Certificate renewal offers two choices: keep the public key from the current
  certificate, or submit a new CSR generated on the device to rotate its keypair.
- Device private keys remain on the device and are never sent to or stored by the
  Gateway during CSR-based renewal.
- Pending external-signature CSRs can be cancelled and removed from the
  certificate list. This removes the Gateway's pending record and any
  undelivered in-memory key. A private key already downloaded cannot be recalled.

## Validation

- Frontend production build completed locally and in the rootless Podman image.
- Backend JavaScript syntax checks passed.
- The deployed admin and broker services reported active; the public HTTPS check
  returned HTTP 200.
- The automated test suite was not run for this release.

## Upgrade

Back up the Gateway data and `gateway.env` before updating. Use `./gateway
backup`, then update with `./gateway update`. Persistent identities, certificates,
and CA data are preserved.
