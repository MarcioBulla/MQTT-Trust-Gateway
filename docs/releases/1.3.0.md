# MQTT Trust Gateway 1.3.0

## Per-device topic rules

- Configure separate publish and subscribe topic filters in **Edit Device → Rules**.
- Use MQTT `+` and `#` wildcards in filters. Empty custom lists deny their respective direction.
- Rules persist with the device and are applied through pending broker changes. The contextual Help article explains the workflow and limitations.

> **Access policy change:** identities without saved rules, including existing identities, default to read/write access on all ordinary MQTT topics (`#`). This is broader than the former identity-specific prefixes. Configure custom rules for devices that need restricted access, then apply the broker changes.

## Update

Review the access policy change before installing through **Settings → System Updates**. Installation requires the signed rootless updater and a verified release. The update coordinates the Admin and broker components and retains the existing recovery process.
