# MQTT Trust Gateway 1.4.6

## Scope and device administration

- Removed the unused Firmware planning tab and its placeholder feature indicator. Device firmware storage and OTA distribution remain responsibilities of an independent service.
- Removed the corresponding Help article and outdated planning references.
- Removed the obsolete per-device firmware planning flag from persisted Gateway state on startup. The cleanup preserves the existing SQLite schema version and does not modify identities, certificates, Rules, CA material, or Health Check history.
- MQTT Device Health Check and its firmware-side MQTT status requirements remain available.

## Compatibility

- No database schema migration is required.
- Gateway self-update, snapshots, integrity checks, and rollback are unchanged.
