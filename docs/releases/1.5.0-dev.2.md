# MQTT Trust Gateway 1.5.0-dev.2

Development prerelease for Beta-channel validation.

- MQTT certificate renewal records a request timeout after 10 minutes without a valid device response. A missing CSR is recorded as `rejected` with `request_timeout`; a missing activation confirmation after `testing` is recorded as `rolled_back` with `confirmation_timeout` after 2 minutes.
- The renewal UI displays the operation status and error detail. Device CSR renewal and editable per-device PKI topics are included for testing.
- Device Health Check reader choices display device labels. Gateway Admin health readiness participates in the API operation queue, and the Admin Quadlet restarts the container after repeated failed readiness probes.

The renewal flow has not yet completed an end-to-end test with AutoBoot_Test. Gateway CA migration remains under development.
